# Running a program

**Run...** in the [system menu](menus.md#the-system-menu) runs a Python script or module as an application, once, without installing it.

## What to enter

Under **Program**, name one of:

- a `.py` script, by typing its path or with **Browse...**
- a module and class, written as `module:Class`

Naming a script is usually all that is needed. The dialog reads it to find its application, looks beside it for a virtual environment, and describes what will run on the line below.

## Options

**Options** shows the application class and the virtual environment, for when the guess is not what you want.

To keep an application in the Applications menu, install it instead: see [Applications](applications.md#installing-an-application).
