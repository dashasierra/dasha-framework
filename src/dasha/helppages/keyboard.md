# The keyboard

Everything can be done from the keyboard. These are the keys as Dasha Desktop comes, and every one of them can be changed in [Settings](settings.md#shortcuts).

## On the desktop

| Key | What it does |
|---|---|
| F1 | Shows the help for what has the focus |
| F10 or Alt+Space | Opens the menu bar |
| F6 | Brings the next window to the front |
| Shift+F6 | Brings the previous window to the front |
| F5 | Maximises the active window, or restores it |
| Alt+F4 or Alt+F3 | Closes the active window |
| Alt+F7 or Ctrl+F5 | Moves the active window |
| Alt+F8 | Resizes the active window |
| Shift+F10 | Opens a context menu |
| Alt+F12 | Leaves for a command prompt |
| Ctrl+Q | Shuts Dasha Desktop down |

## In windows and dialogs

| Key | What it does |
|---|---|
| Tab | Moves to the next control |
| Shift+Tab | Moves to the previous control |
| Enter or Space | Presses the focused button, or else the default one |
| Esc | Cancels a dialog |

In a dialog, a button's highlighted letter presses it. In a window, hold **Alt** with the letter.

## In help

| Key | What it does |
|---|---|
| Tab | Highlights the next link |
| Shift+Tab | Highlights the previous link |
| Enter | Follows the highlighted link |
| Alt+Left | Goes back |
| Alt+Right | Goes forward |
| Alt+Home | Goes to the index |
| Ctrl+F | Searches all the topics |
| Esc | Closes help |

Some terminals keep certain keys for themselves. If a key does nothing, run `dasha --key-test` to see what Dasha Desktop receives, and choose another.
