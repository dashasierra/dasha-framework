# Settings

**Settings...** in the [system menu](menus.md#the-system-menu) changes how Dasha Desktop looks and works. Changes show at once:

- **OK** keeps them and closes.
- **Apply** keeps them and stays open.
- **Cancel** puts them back as they were.

## Appearance

Chooses the theme, and the colour of each part of the screen. Each kind of thing on the screen has its own colour, and help windows have theirs too. A theme can be saved to use again.

## Shortcuts

Lists every action and its keys. Choose an action to add a key to it, by pressing the key, or to take one away. Dasha Desktop checks each change, so that the keyboard can always leave a menu, a dialog and Dasha Desktop itself.

See [the keyboard](keyboard.md) for the keys as they come.

## Desktop

Settings for the desktop itself, such as whether it animates and how it draws colours.

## Applications

Lists the [installed applications](applications.md#installing-an-application), and adds to them or removes them.
