# Menus

The menu bar runs along the top of the screen. It starts with the system menu, then has the active application's menus, and a Window menu for the window in front.

## Using menus

- **F10** or **Alt+Space** opens the menu bar, and closes it again.
- **Alt** and a menu's highlighted letter opens that menu: **Alt+F** for File, say.
- The arrow keys move around the menus, **Enter** chooses an item, and **Esc** closes them.
- Clicking works as you would expect.

The keys shown beside an item choose it without opening the menu. The status bar says what the highlighted item does.

## The system menu

The system menu is the one at the far left, which is there whichever application is active:

| Item | What it does |
|---|---|
| Help | Opens this help |
| About | Says which version of Dasha Desktop this is |
| Settings... | Changes [the settings](settings.md) |
| Themes | Changes the colours of everything on the screen |
| Animations | Turns the animations of windows and menus on or off |
| Command prompt | Leaves for a command prompt: type `exit` to come back |
| Shutdown | Shuts Dasha Desktop down, closing every application |

It also lists the [running applications](applications.md) and any minimised windows, to go back to them.

## Context menus

Right-clicking something, or pressing **Shift+F10**, opens its context menu, if it has one.
