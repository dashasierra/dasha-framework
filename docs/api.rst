API reference
=============

Everything here is generated from Dasha Framework's own docstrings and type
hints, with a page for each module. Each entry says briefly what it is, and
what each of its arguments is; how things work, with examples, is in the
:doc:`architecture guide <architecture>` and the :doc:`tutorial <tutorial>`.
Most applications need only a few of
these modules: ``dasha.application`` to write the application,
``dasha.widgets`` for the controls in its windows, and
``dasha.dialog`` for message boxes and questions.
