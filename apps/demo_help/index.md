# Demo Help

This is the Demo's help, which is a folder of Markdown files beside `demo.py`. Press **Tab** to highlight a link, and **Enter** to follow it.

1. [The Widgets window](widgets.md)
   - [Your name](name.md)

2. [Files](files.md)

Try pressing **F1** on the **Name** box in the Widgets window: help goes straight to the topic for that box.

## On the web

Links outside the help are not opened. Following [Dasha Framework's home page](https://github.com/dashasierra/dasha-framework) copies its address to the clipboard.
